# Set

Status: Completed

## 1. Core Mental Model

**Set = Unique elements ka unordered collection**

Example:

```python
s = {1,2,3}
```

Rules:

```
duplicates allowed nahi
order guaranteed nahi
elements hashable hone chahiye
```

Quick mental model:

```
SET = HASH TABLE
```

Aur yaad rakhne ka shortcut:

```
SET = FAST MEMBERSHIP MACHINE
```

Backend me sets mostly use hote hain:

```
existence check
duplicate removal
visited tracking
permission checking
```

---

# 2. Internal Working (Very Important)

Python set internally:

```
hash table
```

Conceptual flow:

```
value → hash(value) → index in table
```

Example:

```
value = 42
hash(42) → 4382922
4382922 % table_size → slot index
```

Phir element store hota hai us slot me.

Lookup process:

```
1 calculate hash
2 jump to slot
3 compare element
```

Isliye membership check fast hota hai.

Time complexity:

```
average → O(1)
worst → O(n)
```

Worst case tab hota hai jab:

```
too many collisions
```

# 4. Hashing Explained (Simple)

Hashing ka matlab:

```
object → number
```

Example:

```
hash("apple") → 8723492
hash("banana") → 3459834
```

Phir:

```
index = hash % table_size
```

Aur element store ho jata hai.

Important rule:

```
hash must remain stable
```

Isliye sets me sirf **hashable objects** allowed hain.

# 5. Hashable Objects


Not allowed:



Error:

```

```

Reason:


# 8. Set Operations

Sets ka real power yaha hai.

### Union

Combine elements.

```python
A|B
```

Example:

```python
{1,2,3} | {3,4}
```

Result:

```python
{1,2,3,4}
```

Mental model:

```
sab members ek party me
```

---

### Intersection

Common elements.

```python
A & B
```

Example:

```python
{1,2,3} & {2,3,4}
```

Result:

```python
{2,3}
```

Real world:

```
users who bought product A AND B
```

---

### Difference

Elements in A but not B.

```
A-B
```

Example:

```python
{1,2,3} - {2}
```

Result:

```python
{1,3}
```

---

### Symmetric Difference

Elements in either set but not both.

```python
A^B
```

Example:

```python
{1,2,3} ^ {3,4}
```

Result:

```python
{1,2,4}
```

# 10. Set Comprehensions

Syntax:

```python
{expression for item in iterable}
```

Example:

```python
{x * x for x in range(5)}
```

Result:

```python
{0,1,4,9,16}
```

With condition:

```python
{x for x in range(10) if x % 2 == 0}
```

Result:

```python
{0,2,4,6,8}
```

# 13. Memory Model

Set stores:

```
hash
pointer to object
status flag
```

And many empty slots.

Example:

```
100 elements
200 slots allocated
```

Reason:

```
reduce collisions
keep lookup fast
```

Tradeoff:

```
speed ↑
memory ↑
```

# 17. When NOT To Use Sets

Avoid sets when:

```
order important
duplicates important
memory extremely limited
index access needed
```

Example:

```
logs
transaction records
event streams
```
