# Python Loop Notes (Deep Mental Model)

# 1️⃣ FOR LOOP

## Core Mental Model

**Python `for` loop is NOT a traditional counter loop.**

It is an **iterator consumption loop**.

Think:

```python
for item in iterable:
```

means

```
"Give me items one by one from this iterable until it finishes"
```

Python doesn't control the loop.

The **iterable controls the loop**.

---

## Actual Internal Mechanism

Python internally converts:

```python
for x in iterable:
	print(x)
```

into something conceptually like this:

```python
iterator=iter(iterable)

while True:
	try:
		x=next(iterator)
		print(x)
	except StopIteration:
		break
```

### Important pieces

| Function | Meaning |
| --- | --- |
| `iter(obj)` | creates iterator |
| `next(iterator)` | gets next item |
| `StopIteration` | signal that iteration finished |

---

## Memory Model

Example

```python
nums= [10,20,30]

for x in nums:
	print(x)
```

Memory

```python
nums → [10,20,30]

iterator → pointer to nums
           position = 0
```

Execution

```
next() → 10
next() → 20
next() → 30
next() → StopIteration
```

Loop ends.

No copying of list occurs.

---

## Important Concept: Loop Variable Reuse

```python
for x in [1,2,3]:
	pass

print(x)
```

Output

```
3
```

Reason:

Loop variable **remains in scope after loop**.

This is a common beginner surprise.

---

# Iterator Consumption Trap

Example

```python
gen= (x for x in range(3))

for i in gen:
	print(i)

for i in gen:
	print(i)
```

Output

```
0
1
2
```

Second loop prints nothing.

Because **generator already consumed**.

# FOR-ELSE (Important)

Syntax

```python
for item in iterable:
    if condition:
        break
else:
    executed_if_no_break
```

Example

```python
for x in nums:
    if x == 10:
        print("found")
        break
else:
    print("not found")
```

Else executes **only if loop didn't break**.

Rarely understood feature.

---

# FOR Loop Pitfalls

## 1️⃣ Modifying list during iteration

Bad

```python
for x in nums:
    nums.remove(x)
```

Problem

Iterator index shifts.

Correct

```python
for x in nums[:]
```

or

```python
nums = [x for x in nums if condition]
```

---

## 2️⃣ Using range(len())

Bad

```python
for i in range(len(arr)):
```

Better

```python
for value in arr
```

Use enumerate if index needed.

---

## 3️⃣ Unnecessary list conversion

Bad

```python
for x in list(generator):
```

Breaks laziness.

Consumes memory.

---

## 4️⃣ Nested loops explosion

```python
for a in A:
    for b in B:
```

Time complexity

```
O(n²)
```

Dangerous for large datasets.

# 2️⃣ WHILE LOOP

## Core Mental Model

`while` is **condition controlled loop**.

```python
while condition:
```

Means

```
keep running until condition becomes False
```

Unlike `for`, it **does not rely on iterators**.

---

## Memory Model

Example

```python
i = 0

while i < 3:
    print(i)
    i += 1
```

Memory

```
i → 0
```

Loop cycle

```
check condition
execute body
update variable
repeat
```

---

# Infinite Loop

```python
while True:
```

Runs forever.

Needs:

```
break
return
exception
```

to stop.

---

# WHILE-ELSE

Same as for-else.

```python
while condition:
    if something:
        break
else:
    run_if_no_break
```

Rarely used.

---

# Assignment Expression Pattern

Modern Python pattern

```python
while (line := input()) != "exit":
```

Combine assignment + condition.

Very common in:

- streaming input
- file reading
- socket reading

---

# Manual Iterator Pattern

```python
it = iter(data)

while True:
    try:
        item = next(it)
    except StopIteration:
        break
```

This is **how `for` works internally**.

---

# WHILE Loop Pitfalls

## 1️⃣ Infinite loops

Bad

```python
while i < 10:
    print(i)
```

Forgot update.

---

## 2️⃣ Busy loops (CPU burn)

Bad

```python
while True:
    check_status()
```

Without delay.

Fix

```python
time.sleep(1)
```

---

## 3️⃣ Race conditions in multithreading

```python
while queue:
```

Queue might change by another thread.

Use proper queue structures.

# FOR vs WHILE (Important)

| Feature | FOR | WHILE |
| --- | --- | --- |
| Based on | iterable | condition |
| Safe termination | automatic | manual |
| Risk of infinite loop | low | high |
| Common usage | iteration | control loops |
| Pythonic | very | less |

---

# Golden Rule

Use

```
for → when iterating collection
```

Use

```
while → when condition controls loop
```

```
for loops dominate
```
