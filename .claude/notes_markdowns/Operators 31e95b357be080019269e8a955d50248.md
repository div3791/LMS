# Python Operators — Practical Notes (Backend Engineer Version)

# 1. What is an Operator?

An **operator** is a symbol that tells Python to perform an operation on values (operands).

Example:

```
5 + 3
```

Here:

```
5, 3 → operands
+ → operator
```

Result:

```
8
```

---

# 2. Real Mental Model (Important)

Operators are **syntactic sugar for method calls**.

Example:

```python
a + b
```

Python internally does something like:

```python
a.__add__(b)
```

Another example:

```python
a == b
```

Internally:

```python
a.__eq__(b)
```

This is why **custom objects can define operator behavior**.

Example:

```python
class Money:
    def __init__(self, amount):
        self.amount = amount

    def __add__(self, other):
        return Money(self.amount + other.amount)
```

Now this works:

```python
wallet1 + wallet2
```

Real takeaway:

> Operators are shortcuts for function calls.
>

# 3. Types of Python Operators

You mainly need to remember **6 categories**.

---

# 3.1 Arithmetic Operators

Used for mathematical operations.

```python
+
-
*
/
%
**
//
```

Example:

```python
a = 10
b = 3

a + b  → 13
a - b  → 7
a * b  → 30
a / b  → 3.333
a % b  → 1
a // b → 3
a ** b → 1000
```

Explanation:

```python
/  → true division
// → floor division
%  → remainder
** → power
```

Funny analogy:

```python
/  = exact pizza slicing
// = only whole slices allowed
%  = leftover crumbs
```

Example:

```python
10 // 3 = 3 slices
10 % 3 = 1 slice leftover
```

---

# 3.2 Comparison Operators

Used for comparisons.

```python
==
!=
>
<
>=
<=
```

Example:

```python
age = 18

age >= 18
```

Result:

```python
True
```

These operators **always return True or False**.

---

# 3.3 Logical Operators

Combine conditions.

```python
and
or
not
```

Example:

```python
age = 25
citizen = True

age > 18 and citizen
```

Result:

```python
True
```

---

# 4. The MOST Important Mental Model (and / or)

Python **does not always return True/False**.

Instead it returns **actual values**.

---

## AND Rule

```python
A and B
```

Python returns:

```python
first falsy value
OR
last value
```

Examples:

```python
5 and 10 → 10
0 and 10 → 0
"hello" and "world" → "world"
"" and "hello" → ""
```

Funny analogy:

Imagine security guards.

```python
Guard1 AND Guard2
```

If **Guard1 fails → stop immediately**.

If Guard1 passes → check Guard2.

---

## OR Rule

```python
A or B
```

Python returns:

```python
first truthy value
OR
last value
```

Examples:

```python
5 or 10 → 5
0 or 10 → 10
"" or "hello" → "hello"
```

Funny analogy:

Two restaurants.

```
Restaurant1 OR Restaurant2
```

If first is open → eat there.

If closed → go to second.

---

# 5. Truthy vs Falsy Values

Python treats certain values as **False in boolean context**.

Falsy values:

```python
None
False
0
0.0
''
[]
{}
set()
```

Everything else is **Truthy**.

Example:

```python
if []:
    print("hello")
```

Nothing prints because list is empty.

---

# 6. Assignment Operators

Basic assignment:

```python
=
```

Example:

```python
x = 10
```

Shortcut assignments:

```python
+=
-=
*=
/=
%=
```

Example:

```python
x = 10
x += 5
```

Equivalent to:

```python
x = x + 5
```

---

# 7. Identity Operators

Used to check **memory identity**.

```python
is
is not
```

Example:

```python
a = [1,2]
b = [1,2]

a == b → True
a is b → False
```

Why?

Because values same but **memory different**.

---

## Production Rule

Use:

```python
is None
```

Example:

```python
if result is None:
```

Never use:

```python
== None
```

---

# 8. Membership Operators

Check if value exists inside a container.

```python
in
not in
```

Example:

```python
nums = [1,2,3]

2 in nums → True
5 in nums → False
```

---

# 9. Operator Precedence

Python follows priority order.

Simplified order:

```python
1. ()
2. **
3. * / // %
4. + -
5. comparison (< > ==)
6. not
7. and
8. or
```

Example:

```python
5 + 2 * 3
```

Evaluation:

```python
2 * 3 = 6
5 + 6 = 11
```

Use parentheses to avoid confusion.

---

# 10. Short Circuit Evaluation

Python stops evaluation early when result already known.

Example:

```python
False and something()
```

Python **never calls something()**.

Example:

```python
True or something()
```

Again function never runs.

---

## Real Backend Pattern

```python
if user and user.is_admin:
```

Explanation:

```python
user checked first
if None → second condition never executed
```

Prevents crashes.

---

# 11. Default Value Trick (Very Common)

```python
username = input_name or "Guest"
```

Example:

```python
input_name = ""
username = "Guest"
```

Used heavily in backend APIs.

---

# 12. Operator Chaining (Python Special)

Python allows chained comparisons.

Example:

```python
10 < x < 20
```

Equivalent to:

```python
10 < x and x < 20
```

Example:

```python
x = 15
10 < x < 20 → True
```

Cleaner than writing two conditions.

---

# 13. Common Beginner Mistakes

Mistake 1

```python
if a = 5
```

Correct:

```python
if a == 5
```

---

Mistake 2

Confusing `is` and `==`.

```python
== → value comparison
is → memory identity
```

---

Mistake 3

Assuming `and/or` return True/False.

They return **actual values**.

---

# 14. Backend Code Patterns

Safe attribute access:

```python
if user and user.name == "Divyesh":
```

Default fallback:

```python
name = user_input or "Guest"
```

Checking emptiness:

```python
if data:
```

Means:

```python
data exists AND not empty
```

---

# Final Mental Model Summary

```
and → first falsy OR last value
or  → first truthy OR last value
```

Truthy values → almost everything

Falsy values → empty / zero / None

Use parentheses when logic is complex.
