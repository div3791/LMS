# 🧠 4. CSV.READER (LOW LEVEL)

```python
import csv

with open("data.csv", newline='') as f:
    reader = csv.reader(f)

    for row in reader:
        print(row)
```

---

## OUTPUT

```
['101', 'Divyesh', '250']
```

---

## 🧠 MENTAL MODEL

👉 reader = “line ko comma se tod do”

# 🧠 5. DICTREADER (REAL HERO)

```python
import csv

with open("data.csv", newline='') as f:
    reader = csv.DictReader(f)

    for row in reader:
        print(row)
```

---

## OUTPUT

```
{
 'order_id': '101',
 'customer_name': 'Divyesh',
 'amount': '250'
}
```

---

## 🧠 MENTAL MODEL

👉 First row = header

👉 Baaki rows = dictionary mapping

---

## 💡 WHY IMPORTANT

| Problem | DictReader Solution |
| --- | --- |
| Column order change | Safe |
| Readability | High |
| Bugs | Kam |
| Backend friendly | Yes |

---

## 🧠 REAL ANALOGY

reader = bina naam ke dabbe 📦

DictReader = labelled dabbe 🏷️

# 🧠 7. DICTWRITER (PRODUCTION LEVEL)

```python
import csv

with open("data.csv", "w", newline='') as f:
    fieldnames = ["order_id", "customer_name", "amount"]

    writer = csv.DictWriter(f, fieldnames=fieldnames)

    writer.writeheader()

    writer.writerow({
        "order_id": "101",
        "customer_name": "Divyesh",
        "amount": "250"
    })
```

---
