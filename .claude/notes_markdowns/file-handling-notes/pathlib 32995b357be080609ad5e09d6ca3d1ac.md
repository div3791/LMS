# 🔍 Path kya hota hai?

👉 Path = file ka address

```python
Path("/home/divyesh/data/file.txt")
```

👉 Ye string nahi hai

👉 Ye **structured object hai**

---

# 🧠 Lego Model

```
/home / divyesh / data / file.txt
```

👉 Tu:

- add karega (`/`)
- upar jayega (`parent`)
- search karega (`glob`)

---

# 🔥 PATH PARTS

```python
p = Path("/home/divyesh/data/file.txt")
```

| Method | Output | Meaning |
| --- | --- | --- |
| name | file.txt | full name |
| stem | file | without extension |
| suffix | .txt | extension |
| parent | /home/divyesh/data | folder |

---

## ⚠️ Trap

❌ `suffix = txt`

✅ `.txt`

---

# 🔥 PATH JOIN

## ❌ Galat

```python
base + "/file.txt"
```

## ✅ Sahi

```python
base / "file.txt"
```

👉 `/` = operator overloading (andar joinpath)

# 🔥 ABSOLUTE vs RELATIVE PATH

---

## 🟢 Absolute Path

```python
Path("/home/divyesh/file.txt")
```

👉 exact address

---

## 🔴 Relative Path

```python
Path("logs/file.txt")
```

👉 depend karta hai:

> program kaha se run ho raha hai
> 

---

## ⚠️ Biggest Confusion

👉 log sochte hai:

> file location se relate karega
> 

❌ Galat

👉 actual:

> current working directory se relate karega
> 

---

## 🧵 Example

```bash
cd /
python /project/app.py
```

👉 `Path("logs/file.txt")` = `/logs/file.txt` ❌

---

# 🚨 RULE

👉 Production me:

❌ Relative path directly use mat kar

---

## ✅ Correct Pattern

```python
BASE_DIR = Path(__file__).resolve().parent
file = BASE_DIR / "logs" / "app.log"
```

---

# 🔥 `__file__` + resolve + parent

| Step | Meaning |
| --- | --- |
| **file** | current file |
| resolve | absolute |
| parent | folder |

---

# 🧠 `.parent` vs `.parents`

```python
p = Path("/a/b/c/d.txt")
```

| Expression | Result |
| --- | --- |
| parent | /a/b/c |
| parents[0] | /a/b/c |
| parents[1] | /a/b |
| parents[2] | /a |

---

## ⚠️ Trap

```python
.parent.parent.parent
```

👉 fragile code

# 🧠 PART 2 — PATHLIB vs FILE HANDLING

---

# 🔥 IMPORTANT DOUBT (Tera)

> “kya pathlib file module ka replacement hai?”
> 

## ❌ Answer: Nahi

👉 Pathlib = path handling

---

## 🧠 Table

| Kaam | Tool |
| --- | --- |
| path banana | pathlib |

---

# 🔥 Shortcut Methods (Pathlib)

```python
p.read_text()
p.write_text("hello")
```

---

## ⚠️ Limitations

- control nahi
- large file problem
- streaming nahi

---

# 🔥 WITH support

❌ Ye nahi chalega:

```python
with p as f:
```

✅ Ye chalega:

```python
with open(p) as f:
```

---

# 🔥 Async support

❌ Pathlib async nahi hai

---

## Async kaise?

```python
import aiofiles

async with aiofiles.open("file.txt") as f:
    data = await f.read()
```

# 🧠 PART 3 — CONCURRENCY (REAL WORLD PAIN)

| Problem | Example |

# 🧠 Analogy

👉 OS level

---


## 🔵 Queue system (BEST)


👉 file avoid kar
