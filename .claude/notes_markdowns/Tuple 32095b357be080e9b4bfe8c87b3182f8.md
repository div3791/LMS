# 1️⃣ Tuple Kya Hai (Mental Model)

Simple definition:

**Tuple = ordered, immutable collection of objects**

Example:

```python
t = (10,20,30)
```

Important properties:

| Property | Tuple |
| --- | --- |
| Ordered | ✔ |
| Indexing | ✔ |
| Duplicates allowed | ✔ |
| Mutable | ❌ |
| Hashable | ✔ (if elements hashable) |

---

### Desi Analogy

List = **shopping bag**

- items add/remove kar sakte ho

Tuple = **sealed courier box**

- jo andar pack hai wo change nahi hoga

---

# 5️⃣ Tuple Immutability (Important Concept)

Tuple immutable hai.

But **inside objects mutable ho sakte hain**.

Example:

```python
t = (1,2,[3,4])
```

Allowed:

```python
t[2].append(5)
```

Result:

```python
(1,2,[3,4,5])
```

Not allowed:

```python
t[2] = [5,6]
```

Error.

---

### Internal mental model

Tuple stores **references**.

```
tuple
 ├── ref → 1
 ├── ref → 2
 └── ref → list
```

Tuple references change nahi kar sakte.

---

# 6️⃣ Tuple Memory Model

List:

```
list
 ├ size
 ├ capacity
 └ pointer array
```

Tuple:

```
tuple
 └ fixed pointer array
```

Tuple simpler structure hai.

---

### Consequences

Tuple:

- less memory
- faster creation
- slightly faster iteration

---

# 7️⃣ Tuple Hashability

Tuple hashable hota hai **only if all elements hashable ho**.

Example:

Allowed:

```python
(1,2,3)
("a","b")
(1,(2,3))
```

Not allowed:

```python
(1,2,[3])
```

Reason:

list unhashable.

---

### Tuple hash concept

Simplified:

```python
hash(tuple) = combine(hash(e1), hash(e2), hash(e3))
```

# 9️⃣ Tuple Methods

Tuple intentionally minimal hai.

Sirf **2 methods**.

---

### count()

Count occurrences.

Syntax:

```python
tuple.count(value)
```

Example:

```python
t = (1,2,2,3)

t.count(2)
```

Output:

```
2
```

---

### index()

Find first index.

Syntax:

```python
tuple.index(value)
```

Example:

```python
t = (10,20,30)

t.index(20)
```

Output:

```
1
```

# 1️⃣7️⃣ Tuple Pitfalls

### Pitfall 1

Single element tuple bhool jaana.

Wrong:

```python
(5)
```

Correct:

```python
(5,)
```

---

### Pitfall 2

Mutable element inside tuple.

```python
(1,2,[3])
```

Dictionary key banane mein error.

---

### Pitfall 3

Tuple concatenation misuse.

```python
t = t + (5,)
```

Har baar new tuple create hota hai.

Large loops mein slow ho sakta hai.

# 1️⃣8️⃣ Tuple Performance Rule

Use tuple when:

```
structure fixed hai
```

Use list when:

```
data grow/shrink hoga
```
