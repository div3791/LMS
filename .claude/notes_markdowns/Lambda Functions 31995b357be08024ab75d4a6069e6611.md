# 🧠 Lambda Functions

---

## 1️⃣ What is Lambda?

Lambda is a way to create **small, anonymous, inline function objects**.

Syntax:

```python
lambda parameters : expression
```

Example:

```python
lambda x : x * x
```

It creates a function object — just like `def`.

---

## 2️⃣ Why Lambda Exists (Real Reason)

Lambda exists because:

- Python has **higher-order functions** (`map`, `filter`, `sorted`, `min`, `max`)
- These functions accept another function as argument
- Sometimes logic is very small and temporary
- That logic doesn’t deserve a full named function

So instead of:

```python
def get_marks(student):
	return student["marks"]

max(students, key=get_marks)
```

We write:

```python
max(students, key = lambda s : s["marks"])
```

Cleaner for short logic.

---

## 3️⃣ Lambda vs def (Core Difference)

| def | lambda |
| --- | --- |
| Named function | Anonymous function |
| Can have multiple statements | Only one expression |
| Can contain loops, print, try-except | Cannot |
| Good for reusable logic | Good for temporary logic |

### Deep Rule:

If logic deserves a name → use `def`

If logic is disposable → use `lambda`

---

## 4️⃣ Biggest Restriction

Lambda:

- Only one expression
- No assignment
- No multiple statements
- No loops
- No try/except
- No print
- No annotations

This works:

```python
lambda x : x + 1
```

This does NOT:

```python
lambda x :
	y = x + 1
	return y
```

---

## 5️⃣ Where Lambda is Commonly Used

### ✔ map()

```python
map(lambda x : x * 2 , nums)
```

### ✔ filter()

```python
filter(lambda x : x % 2 == 0, nums)
```

### ✔ sorted()

```python
sorted(users, key = lambda u : u.age)
```

### ✔ min() / max()

```python
max(products, key = lambda p : p["price"])
```

---

## 6️⃣ Important Clarifications

### ❌ Lambda is NOT faster

It still creates a function object internally.

### ❌ Lambda is NOT for reducing complexity

It is for reducing verbosity in simple cases.

### ❌ Lambda should NOT replace def everywhere

If code becomes unreadable → you’ve misused lambda.

---

## 7️⃣ Internal Understanding (Important)

When Python sees:

```python
lambda x : x * x
```

It creates a function object in memory.

If you don’t assign it:

```python
map(lambda x : x * x, nums)
```

It still exists temporarily in memory.

It is anonymous because:

- It has no explicit name in your namespace.

But internally, it is still a function object.

---

## 8️⃣ Production-Level Rule (Very Important)

If lambda becomes:

```python
lambda x : x.profile.address.city.name.lower()
```

You are entering dangerous territory.

Reasons:

- Hard to debug
- Hard to test
- Hard to read
- NoneType errors painful

In production:

Short + pure + predictable only.

---

## 9️⃣ Common Beginner Mistakes

1. Assigning lambda to variable unnecessarily:
    
    ```python
    square = lambda x : x * x
    ```
    
    → Just use `def`.
    
2. Writing long unreadable one-liners.
3. Thinking lambda is some advanced magic.
4. Forgetting that lambda is still a function object.

---

## 🔟 Clean Mental Model

Think of lambda as:

📝 Sticky note logic.

Use it when:

- You need small logic
- Only once
- Immediately
- Inside another function call

If logic grows → promote it to `def`.

---

# 🧩 One-Line Summary

Lambda = anonymous, single-expression, temporary function used mostly with higher-order functions.
